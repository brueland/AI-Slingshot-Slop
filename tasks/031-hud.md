# HUD: flight readouts and progress

Create `scripts/ui/hud.gd`, a full-screen Control that shows labels and never blocks the mouse (the player
drags the slingshot underneath it).

```gdscript
class_name Hud
extends Control
## Flight readouts (top left) and progress (top right). Never blocks the mouse.

var distance_label: Label
var height_label: Label
var stars_label: Label
var boosts_label: Label
var best_label: Label
var coins_label: Label
var goal_label: Label
```

`_ready()`:
- `set_anchors_preset(Control.PRESET_FULL_RECT)` and `mouse_filter = Control.MOUSE_FILTER_IGNORE`.
- A `VBoxContainer` at position (16, 16) holding distance, height, stars and boosts labels.
- A second `VBoxContainer` in the top-right corner (`anchor_left = 1.0`, `anchor_right = 1.0`,
  `offset_left = -320`, `offset_right = -16`, `offset_top = 16`) holding best, coins and goal labels.
- Set `mouse_filter = Control.MOUSE_FILTER_IGNORE` on both containers and every label; font size 22
  (`label.add_theme_font_size_override("font_size", 22)`).
- End with `update_flight(0.0, 0.0, 0, 0)` and `update_progress(0.0, 0)`.

Functions (exact texts):
- `func update_flight(distance: float, height: float, stars: int, boosts: int) -> void`:
  `"Distance: %d m" % floori(maxf(distance, 0.0))`, `"Height: %d m" % floori(maxf(height, 0.0))`,
  `"Stars: %d" % stars`, `"Boosts: %d" % boosts`.
- `func update_progress(best: float, coins: int) -> void`: `"Best: %d m" % floori(best)`, `"Coins: %d" % coins`,
  and the goal label: `var next := Milestones.next_milestone(best)`; if empty `"All milestones reached!"`,
  else `"Next: %s at %d m" % [next["name"], int(next["distance"])]`.

## Acceptance criteria
- A Control with `MOUSE_FILTER_IGNORE` and the seven labels.
- `update_flight(123.9, 45.2, 3, 1)` shows "Distance: 123 m", "Height: 45 m", "Stars: 3", "Boosts: 1".
- `update_progress(260, 1234)` shows "Best: 260 m", "Coins: 1234", "Next: Half-K Hero at 500 m".
